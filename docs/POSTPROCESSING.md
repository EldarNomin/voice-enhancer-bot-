# Щадящая постобработка после AI — 2026-09-28

Повторный прогон Natural на сохранённых **raw** выходах DeepFilterNet и GTCRN:
48 условий × 2 движка × 2 варианта = 192 вызова FFmpeg. Те же 30 исходных
открытых записей, что в [AUDIO_COMPARISON.md](AUDIO_COMPARISON.md): 24 английских
парных clean/noisy и 6 русских в четырёх условиях. Варианты отличаются только
вторым `afftdn` (и компенсацией его задержки). EQ/компрессия/loudnorm одинаковы.

| Движок / язык | STOI с повторным denoise | Без повторного denoise |
|---|---:|---:|
| DeepFilterNet / EN | 0.90463 | 0.91172 |
| DeepFilterNet / RU | 0.73407 | 0.75031 |
| GTCRN / EN | 0.88208 | 0.88837 |
| GTCRN / RU | 0.91514 | 0.92746 |

Без повторного denoise метрика выше в 85 из 96 пар. Для GTCRN средние по русским
условиям выросли во всех четырёх группах: clean 0.95208→0.96628,
noise5 0.91171→0.92484, noise15 0.94586→0.95987, echo 0.85090→0.85885.
Это описательная метрика небольшой выборки, без доверительных интервалов;
не доказательство предпочтения слушателя и не гарантия улучшения каждой записи.

Решение: после успешного neural enhancement отключить повторный `afftdn`.
FFmpeg-only и fallback после провала AI сохраняют шумоподавление и компенсацию
25 ms. Тест временного сдвига проверяет обе ветки; пресеты не перенастраивались
под эту выборку. ElevenLabs следует тому же принципу без второго denoise,
но **его реальный звук здесь не измерялся**.

Ограничение: как и в предыдущем отчёте, сохранённые DeepFilterNet ru6 содержат
провал тихой речи **до** защитного fallback. Этот эксперимент изолирует только
постобработку, а не оценивает качество текущего конвейера с fallback целиком.
Raw AI нередко имеет STOI выше, чем любой вариант DSP; обработку «под студию»
всё ещё нужно оценивать на слух. Старый A/B HTML не обновлён и показывает прежний DSP.

Исходные значения: [postprocessing.csv](audio-comparison/postprocessing.csv).
Воспроизведение после подготовки прежнего корпуса и raw AI выходов:

```bash
python scripts/compare_postprocessing.py
```

Платные API при этом не вызываются. Нет оснований оплачивать ElevenLabs по
этому эксперименту: сравнение с ним остаётся отдельной проверкой.
